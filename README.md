3D Residential Model

Overview

The 3D Residential Area Model is a computer graphics project that represents a residential area in a three-dimensional environment. The project aims to demonstrate graphics programming concepts through the visualization of a residential neighborhood.

Objectives

- Create a visual representation of a residential area.
- Apply computer graphics programming concepts.
- Develop a 3D environment representing residential buildings and their surroundings.

Features
